# Происхождение и ограничения

Код и визуализации подготовлены заново для группы 507, №14, 2026.
Оптимизаторы реализованы в `model.py`; NumPy используется для массивов и генератора,
Matplotlib — для графиков. Готовых реализаций ГА, NSGA-II или GP нет.
Все наборы данных синтетические. Фотографии и чужие иллюстрации не используются.
README иллюстрируется реальными графиками результатов.

Отсутствие ошибок подтверждено проверками в указанной среде, но не является гарантией
для любой ОС, версии зависимостей и произвольно изменённой конфигурации.
Файлы `results/environment.json` и `results/tests.log` фиксируют фактическую проверку.

Перед защитой разберите реализацию и соблюдайте правила самостоятельности вашей программы.
